# 🛡️ Insurance AI Project

An intelligent, data-driven web application designed to streamline and automate insurance recomend -related processes using Machine Learning and modern web technologies. 

---

## 🚀 Features
- **AI-Powered Predictions:** Leverages machine learning models to analyze data and deliver smart insights risk assessments.
- **Interactive Web Interface:** Clean and responsive UI built for seamless user experience.
- **Efficient Backend:** Robust backend handling data processing, requests, and model integration.

---

## 🛠️ Tech Stack
- **Languages:** Python
- **Frameworks:** Django 
- **Machine Learning:** Scikit-Learn / Pandas / NumPy 
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite 

---

## ⚙️ How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/arpo1234/Insurance_AI_Project.git](https://github.com/arpo1234/Insurance_AI_Project.git)
   cd Insurance_AI_Project


Create and activate a virtual environment:
python -m venv venv
# On macOS/Linux:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

Run migrations and start the server:
python manage.py runserver

Open in browser:
Open http://127.0.0.1:8000/
